# Nabhadrishti
Nabhadrishti (नभदृष्टि — "Sight of the Skies") is an offline-first AI Copilot &amp; Flight Data Recorder engineered for microgravity science payloads aboard the Bharatiya Antriksh Station (BAS).  In space environments, astronauts face high cognitive loads while conducting multi-step biological, chemical, and physical experiments under microgravity.
